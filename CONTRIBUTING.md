# Contribution Guidelines

Thanks for helping make this list better! Please read the guidelines below before opening a pull request.

## What belongs here

- Resources that are **useful to anyone buying, renting, investing in, analysing, or building products for Dubai real estate**.
- Official government services, well-established apps, active communities, open data, and tools that are genuinely used.
- Free and paid resources are both welcome, as long as they are clearly useful. Promotional or low-quality pages are not.

## How to add a link

1. Search the list first to make sure the resource is not already included.
2. Add the link to the **end** of the most relevant section, using this format:

   ```markdown
   - [Name](https://example.com) - One short sentence describing it.
   ```

3. Keep descriptions in English, concise, and ending with a period.
4. Use `https` links whenever available. Link to the canonical English page if one exists.
5. If you are adding your own project, say so in the pull request description. Self-submissions are fine, but please be honest about it.
6. Make sure your PR title explains the change, e.g. `Add Property Monitor to Data & Analytics`.

## Removing or updating links

Dead links, discontinued services, or outdated information should be removed or updated. Please include a short note explaining why.

## Code of conduct

Be respectful and constructive. We follow the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
